# Prose Review

The contract is three sections of the global instructions: `How to Write`, `Banned Patterns in All Writing`, and `Ghostwriting for Other Humans`. They are already loaded. Do not restate them. `Chat Register` is not part of a review, because it governs the assistant turn rather than an artifact.

## Process

Read the target. Review prose only, since headings, table cells, and list items are exempt.

Report four things, in order.

1. Violations grouped by move, with the quoted text and the bullet that fired.
2. The worst sentences, each routed to one move, each with a rewrite. When two moves prescribe different edits, apply move 2, then 3, then 4.
3. Over-fires. Every rule that fired on text carrying real content that should stay. A rule with an exemption covering the hit goes here, not in item 1.
4. Gaps, where a sentence needs a fact the source lacks. Name the gap. Never fill it.

## Rules of the review

Prose structure first. Typography last, and only where it misleads.

A hit is a question about a sentence, not a verdict. Every bullet carries an exemption and the exemptions are where the judgment is.

Applied as a checklist this catalog lengthens tight prose. Check that a rewrite is shorter than its source, and say so when it is not.

## Editing

Review only, unless asked to apply the edits. When applying them, every fact in the result comes from the source. Invent no number, no name, no date.
